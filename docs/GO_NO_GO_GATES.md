# Research gates and decisions

| Gate | Evidence required | Status on 2026-10-11 |
| --- | --- | --- |
| G0: Scientific charter | Internal v0 draft and verified core prior art | Draft, review needed |
| G1: Laboratory partnership | Written agreement; named lead; model/IFU; appropriate SOP access | NOT MET |
| G2: Ethics and data governance | Approval or waiver; DUA; lawful data and vendor transfer path | NOT MET |
| G3: Case feasibility | Counts by stratum and number with valid paired outcomes | NOT MET |
| G4: Reference standard | Independent experts, adjudication charter, blinded labels | NOT MET |
| G5: Locked protocol | Pilot-informed sample size, endpoints, SAP, pre-registration | NOT MET |
| G6: Frozen evaluation | Dev/test separation, hashed artifacts, immutable model/run logs | NOT MET |
| G7: Public results | Scientific review, patient/IP checks, honest negative results | NOT MET |
| G8: Any clinical system | Separate regulatory, ethics, clinical validation and authorization | OUT OF SCOPE |

Allowed before G1-G5: literature mapping, draft protocol, non-clinical metadata specifications and collaboration materials. Do not implement clinical decision-making rules or execute patient-data/model experiments as if approved.

Decision ownership: clinical validation by laboratory professionals; ethics/data permissions by relevant authorities; statistical protocol by research methodologist; repository process by maintainers.
