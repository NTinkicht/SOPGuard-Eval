# SOPGuard-Eval — simplified project decision gates

**Draft management roadmap, 2026-10-11. Not a replacement for ethics, clinical governance, protocol freezing or statistical oversight.** These three feasibility gates are aligned with the [simplified protocol](PROTOCOL_DRAFT.md).

| Gate | What counts as a pass | Status | Alternative if not met |
| --- | --- | --- | --- |
| **G1 Partner** | Written agreement in principle; named haematology clinical co-investigator; analyser family identified | **OPEN, unmet** | Approach additional sites; review by **15 January 2027**, then consider a published-case-only exploratory paper if no partner after a bounded extension |
| **G2 Volume** | Institutionally authorized aggregate count indicates enough proven interference plus genuine controls to meet a statistical precision target the methodologist considers meaningful | **OPEN, unmet** | Adjust case selection, lookback, interference scope, site count, or report a descriptive pilot honestly |
| **G3 Processing** | Formal authorized ethics/waiver decision, data agreement/access route as applicable, SOP permissions, secure and jurisdiction-compliant model execution | **OPEN, unmet** | Restrict to approved on-premises/local methods, seek permissions or stop patient-level experiments |

## Separate non-negotiable scientific requirements

Passing the feasibility gates is **necessary but not sufficient**. Before any real case-level LLM experiment, a qualified laboratory team must finalize the reference method and analyser-specific procedures; privacy/security personnel must approve access and processing; independent adjudicators must label cases; the time-T0 payload must be audited; a predeclared primary outcome and analysis plan must be frozen and registered before the test set is run.

No raw patient data, restricted SOPs, licensed instrument documentation or linkage records belong in this public repository. Published-case pilot work (if pursued) must be explicitly labelled exploratory and checked for licence/training-data contamination; it cannot be treated as a clinical result.
